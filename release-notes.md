## [1.25.0](https://github.com/chekdata/codex-lb/compare/v1.24.0...v1.25.0) (2026-10-21)


###   BREAKING CHANGES

* **auth:** dashboard 403 denials on permission-gated routes now return code permission_required with param=<permission>. Admin-only reads (conversations, conversation archive, audit log) no longer return admin_access_required, and the re-gated mutations (account credential exports, firewall rules, guest password, upstream-proxy endpoint creation) return permission_required instead of read_only_access to a guest. The read/write session permissions and built-in admin/guest behavior are otherwise unchanged.
* **config:** the env vars above are no longer read. extra="ignore" keeps startup working and each name emits the one-release removed-settings warning; operators relying on the retention env aliases must set the window once in Settings -> Advanced -> Data retention.
* **settings:** CODEX_LB_UPSTREAM_STREAM_TRANSPORT is removed (startup WARN if still set). Operators who pinned it to http/websocket must pin the transport in Settings -> Routing -> Upstream stream transport after upgrade.
